# Frozen evaluation design for the new 15-animal readiness gates

No physiological outcomes have been inspected. READINESS_PROTOCOL.json records the current user requirements, superseding the earlier proposed eight-animal/twelve-neuron acquisition screen for this new experiment only. No original transcriptomic criteria or earlier result is edited.

The authoritative public manifest has 27 putative per-animal files. Generate a fixed 15/6/6 train/validation/final-test allocation by sorting SHA256(`worm-readiness-v1-20261102|animal_id`). This uses file identifiers, never neural or behavioural values. Raw identity/animal assignments and the split table remain private; publish the manifest/hash and group counts only. All sessions/encounters from an animal stay in its group. After exclusions, retain original allocations, report available counts, and do not refill the test set by observed performance. If fewer than 15 animals are usable overall, the requested broad pilot gate fails; a smaller explicitly scoped circuit analysis may still be feasible but is not the requested GO.

Recording-wide technical QC and identity provenance may be audited with fixed rules before fitting; no predictive feature selection, learned transform, state scaling or outcomes-based exclusion uses held-out animals. A descriptive neuron-by-animal class-coverage table is not itself a model feature selector. The >=15-class gate requires the **same** >=15 classes in a common group of >=15 usable animals, not different marginal animal sets. Class counts and individual-neuron counts must both be reported. Keep AVAL/AVAR distinct; unresolved side assignments are class-level evidence only and cannot fill individual-neuron stalks. If the class gate passes but side-resolved coverage fails, report the narrower scientifically defensible state representation rather than silently averaging.

The first diagnostic uses a circuit fixed in advance: ASH, AVA, AIB, RIM, RIB and AVB, with separate left/right labels. Neurons failing training identity/mask gates are not replaced by stronger performers. Use training-only coverage to choose eligible circuit variables and report test missingness. The intended baseline set is receiver-only autoregression, ridge multivariate dynamics, causal sensory/behaviour covariates, and a low-rank or graph-constrained state-space model. Fit the same causal histories and observation masks; no smoothing with future activity. A correlation matrix is an additional descriptive comparator, not direct coupling evidence.

Initial diagnostics use nested held-out animals **within the training 15**. Inner training-animal folds choose ridge strength from the frozen four-value grid; outer training-animal folds estimate feasibility with equal animal weights. Keep validation six and final test six unopened for model selection. An eventual frozen baseline/sheaf comparison can use validation once, then final test once; predeclare the analysis and uncertainty before unlocking them. Shared acquisition dates require an additional day-grouped sensitivity; dates are not independent animals.

Primary neural target is the next observed calcium sample. Raw exported original traces need preprocessing-provenance verification: the name 'original' does not guarantee absence of interpolation, smoothing or future-dependent correction. Require author masks or enough processing metadata to distinguish observations from reconstruction. Missing/noisy states are masked, not filled with zero. Use train-only location/scale, verified units and causal filtering only if parent states are absent; include forecast uncertainty. Valid windows must stay within continuous recording/session segments and cannot cross a gap or idx_splits boundary. Finite signal alone cannot establish optical validity or absence of saturation. Report plateau/constant runs and intensity quantiles; no arbitrary saturation cutoff is inferred without detector metadata.

Primary behavioural target is measured mean forward velocity 1–3 seconds after first entering a 0.2-mm near-boundary band, after at least six seconds outside. Verify the actual circle radius, coordinate units, head position and clock mapping first. Reversal initiation within three seconds is secondary. Head-angle orientation differs across animals and needs independent calibration; absolute signs must not be pooled blindly. Behaviour timestamps may differ from confocal timestamps even when stored vectors have matching lengths. Do not call frame-count equality successful alignment. If only lower-rate behaviour is exported, verify its source alignment and latency before defining targets.

Use only histories available by the prediction cutoff, including prior encounters, distance, speed and heading for every comparator. A neural feature must add value beyond behaviour history and a conventional multivariate/state-space model. Count events, repeated-event animals, positive/negative reversals, target variance and censoring. If targets are degenerate or insufficiently repeated, mark behavioural prediction NOT EVALUABLE and assess neural forecasting separately. No selection of successful avoidance segments.

Readiness GO means recorded states/identities/behaviour and independent animals permit a defensible attempt; it is not validation. Future biological prediction requires the frozen >=5% added-value target and whole-animal uncertainty, robust to lag/mask/density sensitivities. Bootstrapping cells or windows cannot establish animal-level confidence. A small diagnostic is not a final performance claim or a reason to optimize circuit membership.
